## Overview

xpectrass provides an end-to-end workflow for FTIR spectra:

- preprocessing (conversion, denoising, baseline correction, atmospheric correction, normalization)
- exploratory analysis and visualization
- dimensionality reduction and clustering
- classification and model explainability
